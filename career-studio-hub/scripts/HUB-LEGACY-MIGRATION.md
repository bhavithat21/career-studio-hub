2. Pause the old schedule and source writes for the cutover, and pause active Hub discovery/preparation while reviewing the final target snapshot. A `frozenAt` timestamp is an operator declaration; the code also checks source consistency, but does not itself pause either service.
3. Publish the reviewed old-Site route `/api/migration/export`. It requires private Sites service access plus `Authorization: Bearer <export-token>`, enabled migration and a frozen source. It accepts D1/R2 bindings and makes only SELECT/list/get operations.
